# 配置预检与搜索 Key

仅在 get_status 已表明缺少目的地所需 Key、搜索返回实际鉴权/配额错误，或用户明确要求配置 Key 时读取本文件。首次使用本身不触发配置调查；服务与所需搜索源已就绪时直接打开内置浏览器并继续，不查找项目目录、启动代码或 .env 文件。只核对配置状态，不回显或索取完整密钥。

## 检查当前服务配置

1. **先读 [服务与页面门槛](mcp-execution.md#0-先检查服务再打开浏览器最后允许录入)**。复用本轮 `get_status({})` 返回的 url/search/views 检查服务及配置，无结果时才调用；服务未启动调用 `ensure_service({})` 并复核。随后必须实际用内置浏览器打开应用、确认真实 UI 已渲染，必要时用 `get_view_state` 更新并确认本次页面 ready。服务检查和 Key 检查可先做，但不得据此跳过浏览器，页面与连接就绪前不录入。MCP 未接入时如实说明无法核验；可继续文字规划，不能宣称 Key 已配置。
2. 读取 `search.configured` 和 `search.providers.gaode/locationiq`。前者只表示至少一个 Key 非空，不表示所有地区都适用，也不证明 Key 有效或有剩余配额。国内优先高德，国外使用 LocationIQ；只有高德时不能承诺国外可搜索。国内缺高德而已有 LocationIQ 时提示补配国内主力源，可用现有源尝试核验，但不能隐瞒覆盖限制或保证结果。
3. 没有所需可用搜索源时，在搜索/写入前说明缺哪个 Key、用途、申请入口和填写位置。等待用户自行申请并填入；不要反复搜索，也不要把未配置/鉴权失败当成地点不存在。不替用户注册、申请或购买套餐；本地已明确配置的 Key 无需重新申请。

## 用户自行申请并填写

本项目底图与地点搜索是不同能力：底图能显示不代表地点搜索已有凭据。搜索服务需用户自己的 Key，可按服务商当前政策申请免费档或免费配额；不承诺永久免费、无限调用或固定额度，限制以账户与官方页面为准。

| 场景 | 配置项 | 官方申请说明 |
| --- | --- | --- |
| 国内地点搜索、逆地理编码及已接入的国内步行/骑行路线 | `GAODE_KEY` | [高德：创建应用和 Key](https://lbs.amap.com/api/webservice/create-project-and-key)。登录开放平台，创建应用并添加 Key，平台选择 **Web 服务**，不是 Web 端 / JS API |
| 国外地点搜索与逆地理编码；也可用于部分国内地点核验 | `LOCATIONIQ_KEY` | [LocationIQ：Access Token](https://docs.locationiq.com/docs/locationiq-access-token)。用户注册并验证邮箱，在控制台 API Access Tokens 获取 Token；[当前套餐与免费档](https://locationiq.com/pricing) |

填写**实际运行 Travel Story 应用的项目目录**下的 `.env.local`，不是 Skill 文件夹；已有文件只补缺少的项，不覆盖其他设置。不存在时可参照项目的 `.env.example` 创建，不能用示例空值覆盖已有密钥：

```dotenv
GAODE_KEY=用户自己的高德Web服务Key
LOCATIONIQ_KEY=用户自己的LocationIQToken
```

按本次目的地配置需要的项；两项互补，不强制无关服务。密钥只保留在服务端配置，不放进对话、Skill、URL、前端变量或版本库；若应用通过进程环境提供这些变量，也以运行服务的状态为准。

用户填写后，提示按当前运行方式重启应用使环境变量生效，先 `get_status` 核对服务及所需提供方，再实际打开/恢复内置浏览器，确认页面已渲染和连接就绪，然后用本次真实地点搜索核验可用性。`ensure_service` 只复用/启动服务，不是重启接口，不能声称调用它即可重载新 Key；无受控重启方式时请用户重启。已配置但鉴权、限流或额度不足时说明实际错误，请用户检查控制台，不清空或替换其 Key。

Key 尚未补齐时继续可独立完成的需求沟通、天气和攻略研究；暂停依赖缺失源的地点匹配和应用录入，恢复时沿用原计划与已保存行程。
